# Club crest assets

The 36 PNG files in this directory are the 128×128 variants supplied by the project owner from the `ucl-champions-league-2025-2026.football-logos.cc` collection.

Filenames use the stable `leagueTeamCatalog.id` value. UI code must resolve crests through `leagueTeamCatalog.logo` and keep the text fallback supplied by `teamLogoMarkup()`.

Before redistribution outside this project, confirm the applicable trademark and image-use terms with the original source and each club.
